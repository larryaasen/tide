# Agent Rules

The following rules apply to all AI agents interpreting or modifying this project:

1. **Workspace Isolation Constraint**: Antigravity is strictly forbidden from modifying, creating, or deleting any files outside of the current workspace directory. All file system operations must be strictly scoped to this path.
2. **Strict Compilation**: After each and every change to the code, all code must compile without warnings or any compilation errors. Proactively verify compilation to ensure the codebase remains sound.
3. **No Leftover Scripts**: Remove working/temporary scripts (such as Python scripts created for refactoring or manipulating code) as soon as they are no longer needed. Do not leave them lingering in the project directories.
